# Agent guidance

- Edit `index.html`, `demo/index.html`, `src/` and `public/`. Never edit `dist/`: it is generated by `npm run build` and git-ignored.
- Run `npm test`, `npm run typecheck` and `npm run build` before packaging or deploying.
- New code goes in `src/` as strict TypeScript. Classic scripts in `public/` are being converted; don't add new ones.
