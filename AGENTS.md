# Agent guidance

- Edit `index.html`, `demo/index.html`, `src/` and `public/`. Never edit `dist/`: it is generated by `npm run build` and git-ignored.
- Run `npm test`, `npm run typecheck`, `npm run lint` and `npm run build` before packaging or deploying.
- Don't "fix" the `typescript` alias in `package.json`; it is a documented workaround (README, "TypeScript and ESLint").
- New code goes in `src/` as strict TypeScript; stylesheets live in `src/` too, so Vite hashes them. `public/` holds only static assets; don't add scripts or styles there.
